# 🇺🇿 Uzbek Latin Keyboard

**Yangi o‘zbek lotin alifbosi uchun Windows klaviatura dasturi.**

Ushbu loyiha Windows operatsion tizimida yangi o‘zbek lotin harflarini oddiy klaviatura tugmalari orqali yozish imkonini beradi.

## ✨ Imkoniyatlari

- Yangi o‘zbek lotin harflarini yozish.
- Kichik va katta harflarni qo‘llab-quvvatlash.
- Word, Telegram, brauzer va boshqa dasturlarda ishlash.
- Oddiy klaviatura tugmalarini yangi harflarga almashtirish.

## ⌨️ Klaviatura tugmalari

| Klaviatura tugmasi | Natija |
|---|---|
| `W` | ş |
| `Shift + W` | Ş |
| `C` | ç |
| `Shift + C` | Ç |
| `[` | ō |
| `Shift + [` | Ō |
| `]` | ḡ |
| `Shift + ]` | Ḡ |

## 💻 O‘rnatish va foydalanish

1. GitHub sahifasidan `UzbekKeyboard.exe` faylini yuklab oling.
2. Faylni kompyuteringizda ishga tushiring.
3. Dastur ishlayotgan paytda Word, Telegram yoki boshqa matn muharririni oching.
4. Belgilangan tugmalar orqali yangi harflarni yozing.

**Eslatma:** Dastur ishlashi uchun uning oynasi ochiq turishi kerak.

## ⛔ Dasturni to‘xtatish

Dasturni to‘xtatish uchun:

`Ctrl + Alt + F12`

tugmalarini birgalikda bosing.
